KnitKit2 uses libcimbar v0.6.8 (MPL-2.0).
The original 2026-08-21 browser page, receiver, worker and Zstandard scripts are vendored unchanged.
Packaging inlines assets and omits optional PWA registration; camera capture, native CSS, modes, decoding, WASM bytes and memory limits are unchanged.
The shell observes native progress and intercepts complete files for local validation, batch storage and assembly. Pause disposes the embedded page.
Upstream: https://github.com/sz3/libcimbar/tree/v0.6.8 and https://cimbar.org/recv.html
Extension and build source are included in the release source archive.
